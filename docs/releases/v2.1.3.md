# Kiloview Environment Setup 2.1.3

Client setup now explains what remains installed when NDI Tools finishes but PC Agent setup fails later. The error includes the detected Agent and Setup versions, saved-configuration status, the original error, and any NDI restart requirement. Diagnostics also record the verified PC Agent Setup path and its process exit code.

An updated executable does not by itself prove setup completed: subsequent configuration, startup or firewall work can still fail. This release preserves genuine failure reporting and makes repair decisions easier. The specific failure reported on another machine remains unidentified without that machine's diagnostics.

Validation: 106 isolated Windows PowerShell 5.1 regression checks pass, including eleven new cases that run a harmless native process through the real package, version, process-wait and configuration-verification paths. Coverage includes successful older-to-newer upgrades, cancellation, restart, incomplete/mixed versions, failure after replacement, retaining a concurrently installed newer Agent, and corrupt staged archives. The private-desktop installer fixture also passes.

No production vendor installation, live network change or Windows reboot was performed during validation. The complete independently released PC Agent package and its normal licence/adapter/UAC flow remain unchanged.
