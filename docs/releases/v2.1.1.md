# Kiloview Environment Setup v2.1.1

- Pages now size the window to their content, with text wrapping and vertical scrolling on smaller desktops. The red and papaya styling is retained.
- Native progress messages replace the console-style activity pane. Detailed logs stay in diagnostic files and can be exported with **Save diagnostics**.
- NDI Tools installs on a private background desktop, keeping its helper windows and completion launcher out of view. Cleanup is limited to that installer's process tree.
- If GitHub's API returns HTTP 403 or is unavailable, PC Agent setup uses the public latest-release page and the publisher's checksum asset. Package size, SHA-256, archive paths and binary identity remain verified.
- PowerShell network, deployment, restart and startup commands use hidden windows throughout the native app.

Validation: 75 regression checks, layout checks from 100% through 250% scaling on full and constrained desktops, a harmless native installer fixture covering hidden GUI children and cleanup, and live public PC Agent metadata verification in Windows PowerShell 5.1. A full vendor installation and server reboot were not run on the development machine.

Production Toolkit v1.3.1 separately adds automatic card refresh after its installer or **Open setup** window closes.
